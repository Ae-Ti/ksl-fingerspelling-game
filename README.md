# 지문자 자음 맞히기

웹캠 앞에서 한국수어 지문자로 자음 14개(ㄱ~ㅎ)를 만들면 알아보는 브라우저 게임입니다.

- 플레이: https://ae-ti.github.io/ksl-fingerspelling-game/
- 설치할 것 없이 최신 Chrome·Edge·Safari에서 열면 됩니다. 처음에 카메라 권한을 묻습니다.
- 영상은 브라우저 안에서만 처리합니다. 서버가 없고, 영상과 손 관절 좌표를 어디에도 보내지 않습니다.

## 할 수 있는 것

| 모드 | 내용 |
| --- | --- |
| 연습 | 지금 손모양과 가까운 자음 3개를 실시간으로 보여 줍니다. 자음을 고르면 그 자음을 목표로 연습하고, 맞히면 다음 자음으로 넘어갑니다. |
| 60초 도전 | 나오는 자음을 손으로 만들면 점수를 얻습니다. 연속으로 맞히면 점수가 더 오르고, 4초가 지나면 기준 손모양 힌트가 나옵니다. 막히면 건너뛸 수 있습니다(스페이스 바). |
| 기준 만들기 | 내 손으로 자음별 기준 손모양을 녹화합니다(3초 뒤 2초 동안). 녹화한 기준은 이 브라우저에만 저장되고, JSON 파일로 저장하거나 불러올 수 있습니다. '기준 점검'으로 녹화끼리 서로 맞혀 보며 헷갈리는 자음을 찾습니다. |

## 동작 방식

```
웹캠 영상 → 손 관절 21개(MediaPipe Hand Landmarker, 브라우저에서 실행)
         → 특징 90개(위치·마디 각도·손끝 거리·손바닥 방향)
         → 기준 손모양과 k-최근접 이웃 비교 → 최근 5프레임 다수결 → 0.45초 유지하면 확정
```

1. **손 관절 찾기**: Google MediaPipe Hand Landmarker를 웹어셈블리로 브라우저에서 실행해, 프레임마다 손 관절 21개의 좌표를 얻습니다.
2. **특징 만들기** (`js/features.js`): 손목을 원점으로, 손바닥 길이(손목~중지 뿌리)를 1로 맞춰 손 위치·크기와 상관없게 합니다. 지문자는 같은 손모양이라도 손가락이 향하는 방향에 따라 다른 자음이 되므로 회전은 지우지 않았습니다. 왼손은 좌우를 뒤집어 오른손과 같은 기준으로 비교합니다.
3. **비교하기** (`js/classifier.js`): 녹화해 둔 기준 표본 중 가장 가까운 7개가 거리에 따라 투표합니다. 같은 자음 표본끼리의 거리 분포로 '기준과 너무 다른 손모양' 경계를 정해, 아무 손모양이나 자음으로 잡지 않게 했습니다.
4. **흔들림 줄이기**: 최근 5프레임 다수결로 한두 프레임 튀는 결과를 무시하고, 같은 자음을 0.45초 유지해야 확정합니다. 확정한 손모양을 계속 들고 있어도 다시 확정하지 않습니다.

학습된 분류 모델 대신 최근접 이웃을 쓴 이유: 자음 14개는 움직임 없는 손모양이고 자음마다 표본이 수십 개뿐이며, 방문자가 자기 손으로 녹화한 기준을 바로 써야 하기 때문입니다. 녹화하면 학습 과정 없이 곧바로 기준에 들어갑니다.

## 만든 과정

- **배경**: 캡스톤디자인에서 텍스트를 수어 아바타로 보여 주는 부분(Blender 아바타 제작·코드 제어, 웹 렌더링)을 맡았습니다. 이 게임은 그 반대 방향, 사람이 만든 수어 손모양을 웹캠으로 알아보는 쪽을 작게 만든 것입니다.
- **범위**: 처음에는 아바타가 수어를 보여 주고 맞히는 게임을 생각했으나, 하루 안에 만들 수 있게 웹캠 인식으로 바꾸고, 그중 손모양이 고정된 지문자 자음 14개로 범위를 정했습니다.
- **AI와 나눈 일**: Claude(Anthropic)와 대화하며 만들었습니다.
  - 배태일: 무엇을 만들지와 범위 결정, 한국수어사전을 보고 기준 손모양 녹화, 실제 웹캠으로 시험하고 고칠 점 정하기
  - Claude: 코드·테스트 작성, 화면 디자인
- **검증**
  - 단위 테스트 32개(`npm test`): 특징 계산(위치·크기 무관, 방향 구분, 왼손 맞춤), 분류기, 흔들림 보정, 게임 규칙, 기준 저장소
  - 화면 흐름 자동 테스트 12개(`tools/e2e.py`): 카메라 대신 가짜 손 관절 데이터를 넣어 연습·60초 도전·기준 만들기 흐름 확인
  - 기준 점검: 녹화를 묶음 단위로 빼고 나머지 녹화로 맞혀 보는 교차 검증(같은 녹화 안의 프레임끼리는 거의 같아서 묶음 단위로 뺍니다)

## 직접 실행하기

```sh
python3 -m http.server 8000   # http://localhost:8000 (카메라는 localhost나 https에서만 켜집니다)
npm test                       # 단위 테스트 (Node 22 이상)
python3 tools/e2e.py /tmp/shots   # 화면 흐름 테스트와 스크린샷 (Playwright 필요)
```

빌드 과정은 없습니다. `index.html`과 `js/` 모듈을 그대로 GitHub Pages로 배포합니다.

## 파일

| 경로 | 역할 |
| --- | --- |
| `js/tracker.js` | 카메라, MediaPipe 손 관절 찾기 |
| `js/features.js` | 손 관절 → 특징 |
| `js/classifier.js` | k-최근접 이웃, 기준 점검, 흔들림 보정 |
| `js/game.js` | 60초 도전 규칙 |
| `js/templates.js` | 기준 손모양 저장(브라우저 저장소, 기본 기준 합치기) |
| `js/main.js` | 화면 |
| `data/templates.json` | 사이트에 넣은 기본 기준 손모양(손 관절 좌표) |
| `tools/subset-fonts.py` | 페이지에 쓰는 글자만 남긴 웹폰트 만들기 |
